# 11-11-THE-TIME-LOOP-ADVENTURES
11:11-The time loop is a 2d action adventure platformer game developed using python and pygame
Step into a mysterious futuristic world where time is your greatest power. Explore different dimensions, collect hidden time shards, defeat enemies, unlock portals, and challenge the powerful Time Guardian.
✨ Game Features

- Double Jump and Time Dash abilities
- Time Rewind mechanics
- Multiple levels and dimensions
- Checkpoints and respawn system
- Enemy battles and final Boss Fight
- Collectibles and scoring system
- Health and countdown timer
- Neon-inspired futuristic environments

🎮 Controls

- A / D – Move
- SPACE – Jump / Double Jump
- SHIFT – Time Dash
- J – Attack
- R – Rewind Time
- P / ESC – Pause

🛠️ Technologies Used

- Python
- Pygame

Can you break the loop before time runs out?

One world. Four dimensions. Infinite possibilities.
